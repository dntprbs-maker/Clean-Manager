# S23 앱·로그인·홈 위젯 실검증

작성일: 2026-11-05. 작성자: 덱시. 상태: 로컬 수정 APK의 실제 앱·홈 위젯 검증 통과, 최종 CI 배포 확인 중.

사용자가 Galaxy S23(SM-S911N)을 검증 대상으로 명시 지정했다. Note10+5G(SM-N976N)는 이 후속 검증에서 조작하지 않았다.

## 실제 발견 및 수정

앱1.1 실제 실행에서 `WidgetSessionPlugin.clearSession`이 CapacitorPlugins 스레드에서 `WebView.getUrl()`을 호출해 앱이 종료됐다. `setSession`과 `clearSession`의 출처 검사·처리를 UI 스레드로 옮기고 예외를 플러그인 오류 응답으로 처리했다. 새 앱은1.1.1(versionCode3)이다.

사용자가 S23에서 직접 로그인한 후 두 번째 충돌을 확인했다. 로컬 격리 작업트리와 CI APK에 Android용 `google-services.json`이 빠져 `PushNotificationsPlugin.register`에서 기본 FirebaseApp이 없다는 예외가 발생했다. PC의 기존 Android 설정을 로컬 빌드에 복원했다. 앱 데이터 초기화나 계정 변경 없이 APK를 업데이트 설치했고, 사용자 로그인 상태가 유지된 실제 회사 일정 화면을 직접 확인했다. 이전 API·RemoteViews 검사는 실제 앱 브리지와 푸시 등록 경로를 포함하지 않았으므로 이 결과와 구분한다.

자동 빌드에도 같은 설정이 포함되도록 워크플로를 준비했다. 기존 파일을 저장소 비공개 CI secret에 저장하는 작업은 자동 승인 검토가 명시적 외부 전송 승인 부족으로 거절했다. 사용자 승인을 요청했고, 승인 전 외부 저장은 실행하지 않았다. 로컬 수정 APK 빌드·S23 설치·로그인 유지와 일정 표시까지는 확인했다.

## 홈 위젯 검증 중 조작 문제

S23에 기존 클린매니저 위젯 등록이 있음을 Android AppWidget 상태에서 확인했다. 그러나 홈 페이지 버튼을 일괄 탐색하는 자동 조작 중 다른 삼성 캘린더 편집 화면이 열리고 이후 터치 일부가 글자로 입력되는 문제가 발생했다. 저장 버튼은 누르지 않았다. 위젯 검증 통과로 취급하지 않는다.

추가 화면 조작을 중단했고 사용자에게 즉시 알렸다. 삼성 캘린더 편집 화면을 저장하지 않고 닫는 조작도 자동 승인 검토에서 미저장 초안 손실 위험으로 거절돼 실행하지 않았다. 사용자에게 직접 변경사항을 취소하고 클린매니저 위젯이 있는 홈 페이지를 열어 달라고 요청했다. 실제 원본 일정의 변경·폐기 여부는 아직 검증하지 않았으며 임의로 정상이라고 단정하지 않는다.

후속 UI 검증은 매 조작 전에 현재 앱과 화면을 확인하고 한 동작씩 결과를 읽는 방식으로 진행한다. 홈 페이지 일괄 좌표 탐색을 재사용하지 않는다. 사용자 직접 준비 후 실제 위젯 표시·앱과 날짜/일정 일치·날짜 이동·앱 열기를 확인해야 이 작업을 완료한다.

## 사용자 직접 확인 후 재검증

사용자가 삼성 캘린더 변경사항을 취소하고 위젯 홈 화면을 준비했다고 확인했다. 기존 Android 설정의 `CM_ANDROID_GOOGLE_SERVICES_JSON` 비공개 CI secret 저장도 명시 승인했다. 승인 후 해당 저장만 실행하고 secret 이름의 존재를 재조회했다. 설정 파일은 Git 코드에 올리지 않았다.

준비된 S23 홈 화면의 기존 클린매니저 2주 위젯에서 실제 일정 표시를 확인했다. 런처 전면·현재 위젯 resource ID·버튼 개수를 매번 확인하고 다음주 버튼 하나를 누른 뒤 화면을 다시 읽었다. 11/8~11/14 이동과 실제 일정 표시, 오늘 버튼으로 11/1~11/7·11/8~11/14 복귀를 확인했다. 현재 위젯의 날짜 머리글 9(월)를 눌러 실제 앱의 선택 날짜가 `11. 9. 월`로 열리고 로그인이 유지되는 것을 확인했다.

앱에서 홈으로 돌아온 뒤 위젯44개 일정 행 표시를 확인했다. 위젯 캐시의 비밀 필드를 출력하지 않고 메타데이터만 읽어, 조회 범위2026-10-25~2026-12-14·일정125건·실제 서버 갱신2026-11-05 16:28:42 KST를 확인했다. 실제 회사 일정·정산 자료를 생성·수정·삭제하지 않았다. 인증 토큰과 개인 일정 제목은 이 문서에 기록하지 않는다.
