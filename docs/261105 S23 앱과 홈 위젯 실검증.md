# Android 앱 실행과 위젯 연동 수정

작성일: 2026-11-05. 작성자: 덱시.

실제 앱의 네이티브 경로를 확인하면서 API와 RemoteViews 검사만으로는 발견하지 못한 앱 종료 원인 두 가지를 수정했다.

1. Capacitor 플러그인 스레드에서 WebView.getUrl을 호출하던 출처 검사를 UI 스레드에서 실행하도록 변경했다. 세션 설정과 해제의 실패는 플러그인 거부 응답으로 전달한다.
2. Android Firebase 클라이언트 설정이 빌드에 누락되면 푸시 등록에서 기본 FirebaseApp 초기화가 실패했다. 자동 빌드가 비공개 CI secret에서 설정을 복원하고 프로젝트 및 Android 패키지 일치를 확인하도록 했다. 설정 원문은 Git에 포함하지 않는다.

앱 버전은1.1.1(versionCode3)이다. 수정 앱과 계측 APK의 로컬 빌드 및 실제 앱 실행, 인증 복원, 홈 위젯 표시, 주간 이동과 오늘 복귀, 위젯 날짜에서 앱의 같은 날짜 열기, 인증된 갱신을 확인했다. 최종 CI 산출물 설치 검증은 배포 후 확인한다.

운영 자료나 개인 정보를 포함한 상세 검증 이력은 공개 코드 문서에 싣지 않고 별도 작업 기록에 보존한다. 화면 검증은 현재 화면과 대상 요소를 매 동작 전에 확인하고 한 번씩 수행한다.
