# 앱·위젯 일정 공유

Android 앱에서 받은 서버 응답을 홈 위젯도 사용하도록 연결한다. 기존 브라우저와 이전 APK는 기존 조회 방식을 유지한다.

- 설치된 위젯이 새 자료를 필요로 할 때 앱과 위젯의 기간을 합쳐 일정 원본을 한 번 조회한다. 앱 응답에는 앱 기간의 일정·보고서만, 공유 응답에는 권한 확인한 위젯용 최소 항목만 포함한다.
- 위젯이 없거나 동일 변경 번호의 캐시가 유효하면 앱 조회 기간을 넓히지 않는다. 앱은 작은 변경 번호 확인으로 놓친 푸시도 보완한다.
- 네이티브 공유 티켓은 계정·기간·로컬 변경 세대와 연결하고 유효시간을 제한한다. 빈 결과도 완전한 기간 응답으로 저장한다. 이전 계정·과거 티켓·변경 도중 응답과 민감 필드는 거부한다.
- 앱과 위젯 조회가 겹치면 공유 응답을 기다리며, 만료·실패 시 위젯의 독립 갱신을 유지한다. 선택적 브리지의 응답 누락에도 앱 일정 화면은 기존 경로로 동작한다.
- 공유 앱 조회 경로에서도 관리자의 보존 보고 이력을 유지하며, 여러 허용 반복 예외가 같은 시리즈에 있으면 원래 회차를 구분해 상세 화면을 유지한다. 정산은 기존 자료·서버 확정 경로를 유지한다.

검증은 서버 단위·에뮬레이터 권한/기간/보고이력, 실제 브라우저 일정·목록·정산·재무·새앱/구앱/위젯없음/콜백누락 흐름과 Android 단위·격리 실기기 시험으로 수행한다. 운영 배포·최종 APK의 실제 화면 확인은 작업 원장에 기록한다.

공유 대상은 같은 Android 기기의 표시 자료다. 위젯 요약으로 편집·보고서·정산 원본을 대체하지 않으며, 앱 종료 상태의 위젯 독립 갱신과 서버 권한 확인 비용은 유지한다. 외부 저장 서비스는 추가하지 않는다.
