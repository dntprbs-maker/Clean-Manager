# 청소비 아코디언 입력

기존 일정 추가·수정 화면의 연락처 아래에 선택 입력 아코디언을 둔다. 기본은 접힌 상태이며, 펼치는 것만으로 `finance`를 생성하지 않는다. 기존 파란 저장 버튼으로 일정과 함께 저장한다.

청소비, 팀장 일괄/팀원 직접 지급, 지급액, 항목별 추가 비용을 입력하며 예상 손익은 `청소비 - 선택한 지급 방식의 지급액 합계 - 추가 비용 합계`다. 숫자는 원 단위 비음수 정수이며 잘못된 입력·범위 초과·이름 없는 팀원·중복 팀원·항목명 없는 비용을 저장 전에 검사한다. 손실과 0원은 허용한다.

기존 `finance.revenue`, `payMethod`, `leaderPay`, `memberPays`, `extraCosts` 구조를 재사용한다. 기존 지급완료 상태, 작업자 및 추가 필드는 보존한다. 지급 방식을 바꿔도 다른 방식의 입력은 지우지 않으며 합계에는 현재 선택한 방식만 반영한다. 편집하지 않은 금액 객체는 그대로 저장하고, 반복 일정은 기존 전체/이 회차/이후 전체 저장 경로를 사용한다. 복사 일정은 기존 동작대로 원본 금액을 자동 복사하지 않는다.

노출·편집은 기존 사장/관리 권한을 따르고 일반 직원에게 입력기를 노출하지 않는다. 정기청소 월 급여나 실제 송금·지급완료 처리를 자동 실행하지 않는다. 상세 화면의 기존 금액 수정 버튼은 실제 일정 수정 화면으로 연결한다.

검증: `test/eventFinance.test.js`, `test/eventFinance.screen.mjs`. 브라우저 시험은 demo 에뮬레이터만 사용하며 실제 폼의 접힘/펼침, 저장 후 재열기, 팀원별 지급, 메타데이터 보존, 음수 차단, 금액 없이 등록, 반복 회차별 금액, 일반 직원 비노출을 확인한다.
